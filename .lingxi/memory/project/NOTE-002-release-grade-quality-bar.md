# NOTE-002 Release-Grade Completeness Over Placeholder Progress

- Status: approved
- Type: engineering-taste
- Durability: high

## Preference

Use “best practice quality” and “no-missing-piece acceptance” as the delivery bar. Avoid placeholder implementations that defer core quality to later cleanup; ship production-usable artifacts at each accepted milestone.

## Apply When

- Breaking down milestones and defining done criteria.
- Deciding between fast scaffolding vs. production-ready implementation.
