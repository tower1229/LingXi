# LingXi Privacy Policy

Effective date: April 11, 2026

LingXi is an open-source Codex plugin distributed from the LingXi repository.

## What LingXi processes

LingXi processes the repository content, prompts, task documents, and local runtime data needed to run its task, vet, and memory workflows.

## Where data is stored

When LingXi is installed in a repository, it may write local runtime data under paths such as `.lingxi/` and `.codex/agents/` inside that repository. LingXi does not include a hosted LingXi service that collects repository data by default.

## Third-party services

LingXi runs inside Codex and may rely on Codex features, local Node.js execution, and any services the user separately connects in Codex. Those services are governed by their own terms and privacy policies.

## Data control

Users control whether LingXi is installed, whether its automation is registered, and whether generated local runtime files are retained or removed.
