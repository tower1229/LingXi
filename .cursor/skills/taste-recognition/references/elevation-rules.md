# 升维规则（Elevation Rules）

**在实现中的位置**：本规则在 taste-recognition 的**执行步骤**中，于「模式靠拢」之后、「产出 payload」之前执行；用于决定写/不写及 layer（L0/L1/L0+L1）。判定为不写时不产出该条 payload，主 Agent 不因此条调用 lingxi-memory。

---

## 1. 升维判定的维度定义（每维 0–2 分）

| 维度 | 含义 | 0 | 1 | 2 |
|------|------|---|---|---|
| **D1 决策增益** | 该条对未来类似决策的帮助 | 几乎无 | 有 | 显著 |
| **D2 可复用/可触发** | 能否跨场景复用、是否易被检索命中；**若已匹配设计模式则本维至少 1** | 单次/单点 | 场景内可复用或可触发 | 跨场景可复用、易被检索 |
| **D3 可验证性** | 是否有用户原文或可验证事实 | 无 | 有用户表述或可验证事实 | 有明确证据或可复现 |
| **D4 稳定性** | 非一次性、非高时效 | 一次性/高时效 | 一段时间内有效 | 长期有效 |

**总分 T = D1 + D2 + D3 + D4**（满分 8 分）。

---

## 1.1 按内容类型的评分指引（不改变 D1–D4 定义与 T/layer 公式）

内容类型定义见 [references/content-types.md](content-types.md)。以下为评分时的补充指引：

- **决策经验**：若存在明确 alternatives（principles 中非 choice 项）且用户给出了理由，D1 至少 1、D2 至少 1。
- **领域知识 / 排障**：若有用户原文或可复现步骤，D3 优先考虑 1～2；排障类若可迁移到同类问题，D4 可给 1～2。
- **反例与约束**：与偏好同等参与升维；表达清晰且场景可触发时 D2 可给 1。
- **一次性/高时效**：维持现有例外（D4=0 且一次性默认不写）；仅在 D1=2 且 D2≥1 时允许 L1 弱版本，并在 payload 或下游 note 中标注适用边界。

---

## 2. 写/不写

- **T ≤ 3**：不写。不产出该条 payload，不加入 payloads 数组；主 Agent 不因此条调用 lingxi-memory。
- **T ≥ 4**：进入 layer 判定；若未触犯下述例外，则产出 payload 并填写 layer、可选 l0OneLiner/l1OneLiner。

---

## 3. layer 判定（仅对 T ≥ 4 的条）

- **T ∈ [4,5] 且 D3 ≥ 1** → `layer: "L0"`（仅事实层）。若 D3 = 0，则仍不写（与例外一致）。
- **T ∈ [6,7] 且 D1+D2 ≥ 3** → `layer: "L1"`（原则层）。
- **T ≥ 8 且 D2 ≥ 1 且 D3 ≥ 1** → `layer: "L0+L1"`（双层）。

---

## 4. 例外条件

- **D3 = 0**：不单独写 L1；可写 L0 仅当 T∈[4,5] 且其他维度允许（实际因 D3=0 常导致不写或仅弱 L0）。
- **D4 = 0 且一次性**：默认不写。除非 **D1 = 2 且 D2 ≥ 1**，可写 L1 弱版本，并在 payload 或下游 note 中标注适用边界。
- **存在明显反例或冲突记忆**：不在此处过滤，交由下游 lingxi-memory 治理（merge/replace/veto）；taste-recognition 仍可产出 payload。

---

## 5. 书写模板（供生成 l0OneLiner / l1OneLiner）

- **L0**（事实层）：在 [具体场景] 下发生了 [可验证事实/操作]，导致 [结果]。
- **L1**（原则层）：在 [场景族] 中优先 [策略]，避免 [反策略]，因为 [目标/风险]。

下游 lingxi-memory 可直接采用 payload 内的 l0OneLiner、l1OneLiner 写入 note；若无则按 scene + choice 生成。

---

## 6. 与模式靠拢的关系

- **先做模式靠拢**（参考 pattern-catalog），再对**升维后的** scene/principles/choice 做升维判定。
- 匹配到设计模式时：填写 `patternHint`、`patternConfidence`；**D2 至少为 1**（可复用/可触发维度因模式名而提升）。
